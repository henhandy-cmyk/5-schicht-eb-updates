# 5-Schicht mit EB – Android-App

Schichtkalender für das 5-Schicht-Modell mit 35-Tage-Rhythmus. Kostenlose Software (Freeware),
Weitergabe nur unverändert und kostenlos. Verbindlich ist allein der offizielle Dienstplan des Arbeitgebers –
alle Angaben ohne Gewähr. Keine offizielle App eines Arbeitgebers.

Diese Ablage enthält nur die fertigen Android-Dateien (APK) und die Anleitung, keinen Quellcode.
Die App sucht selbst täglich nach Updates (abschaltbar) – dafür wird diese Ablage genutzt.

Installieren: APK-Datei auf dem Android-Handy antippen und „Installieren“ wählen. Android fragt einmalig,
ob die App, mit der du die Datei öffnest, unbekannte Apps installieren darf. Ein Update einfach über die
vorhandene App installieren – die Daten bleiben erhalten. Einzelheiten stehen in der Anleitung.
